# Vienna Simulation Repository

Historical versions of bacterial/phage simulation models.

## Structure

- simulation_1: early bacterial nutrient/channel model
- simulation_2: channel dynamics and meal/refill model
- simulation_3: expanded analysis/sweep version
- simulation_p: phage prototype version
- simulation_5: larger Python bacterial-phage model
- simulation_5_clear: cleaner analysis/simulation version
- simulation_sampling: sampling/parameter exploration version
- simulation_t: testing/analysis version
- simulation_6: C++ rewrite

Generated data, plots, caches, binaries, and build outputs are ignored.
