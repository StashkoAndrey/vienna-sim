Main SIM6 bacterial/phage simulation version.

This folder contains the updated C++ simulation code for bacterial growth, phage interaction, receptor/channel behavior, switching logic, and simulation metrics.

Important changes:
- updated bacteria and phage logic
- updated simulation grid code
- added/updated simulation metrics files
- added switch/model-analysis support scripts
- generated outputs are excluded from Git

Tracked content:
- C++ source/header files
- Python scripts
- parameters/configuration files
- documentation

Ignored content:
- CSV outputs
- PNG plots
- pickle files
- compiled executables
- logs
