# simulation_6_modelcompare

SIM6 model-comparison version.

This folder contains the model-comparison version of the SIM6 bacterial/phage simulation.

Purpose:
- compare alternative SIM6 model variants
- test switching/mutation/selection assumptions
- keep model-comparison code separate from the main SIM6 folder
- allow rebuilding the local Windows executable from source

Tracked content:
- C++ source/header files
- Python helper scripts
- parameters/configuration files
- documentation

Ignored content:
- compiled executables
- CSV outputs
- PNG plots
- pickle files
- logs
- sweep/result folders

Note:
Executables are intentionally not tracked. Rebuild locally from the source files.
